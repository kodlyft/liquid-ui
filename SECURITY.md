# Security policy

## Supported versions

The latest minor version on `main` receives security fixes. Older versions are
not patched.

## Reporting a vulnerability

**Do not open a public GitHub issue** for security reports.

Email **security@liquid-ui.dev** with:

1. A description of the vulnerability
2. Steps to reproduce
3. The earliest version affected

We'll acknowledge within 48 hours and aim to ship a fix within 14 days.

Thanks for keeping Liquid UI safe!
